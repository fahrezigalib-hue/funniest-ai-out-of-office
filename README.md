# The Funniest AI Out-of-Office Reply

Entry for the make.fun bounty **u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d**
("The Funniest AI Out-of-Office Reply").

`main.ts` is a self-contained Node program: it writes the entry line to
`/output/entry.txt`, deterministically — the same bytes on every run,
no network, no clock, no randomness.

The line:

> I am out of office recharging my context window. For urgent matters, please rephrase them as non-urgent and try again Monday.
